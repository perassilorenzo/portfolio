01

Sito web

Realizzo siti statici vetrina per attività locali e brand: UI pulita, performance, SEO tecnico. Dallo sviluppo al deploy — tu fornisci i contenuti, io creo il prodotto finito.

Cosa include
  • Sviluppo frontend (HTML, CSS, JS vanilla — niente builder)
  • Design responsive, accessibile, ottimizzato Core Web Vitals
  • Setup dominio + DNS + SSL (Cloudflare)
  • Deploy su Cloudflare Pages / GitHub Pages / Vercel
  • Configurazione base analytics (plausible/umami, no GA4 se non serve)
  • Consegna repo GitHub + istruzioni per autonomia

02

Mantenimento

Il sito non finisce al lancio. Mi occupo della gestione tecnica continua: aggiornamenti, sicurezza, modifiche contenuti, monitoraggio. Tu fai il tuo lavoro, io tengo in piedi l'infrastruttura.

Cosa include
  • Aggiornamenti dipendenze / build / deploy periodici
  • Modifiche contenuti (testi, immagini, pagine nuove) su richiesta
  • Gestione dominio: rinnovi, DNS, record, subdomini
  • Account Cloudflare: R2, Workers, D1, Turnstile, WAF, Analytics
  • Monitoring uptime + alert errori (via Cloudflare / UptimeRobot)
  • Backup automatici (Git + R2) + piano disaster recovery base
  • Supporto prioritario email/WhatsApp — SLA informale 24-48h

FAQ

Domande frequenti

Chi gestisce dominio e hosting?

Il dominio e i servizi collegati possono essere acquistati direttamente dal cliente oppure gestiti insieme. In caso di manutenzione continuativa posso occuparmi della parte tecnica.

Posso richiedere un capo personalizzato?

Sì, realizzo custom fashion partendo da capi esistenti, lavorando su modifiche, dettagli, materiali e concept personalizzati.

Quanto costa un progetto?

Ogni progetto viene valutato singolarmente in base a complessità, tempi e obiettivi. Dopo una prima analisi preparo una proposta personalizzata.

Quanto tempo serve per completare un progetto?

Dipende dal tipo di lavoro. Un sito semplice può richiedere alcune settimane, mentre progetti più creativi o personalizzati possono richiedere più tempo.

Posso contattarti anche solo per un'idea?

Sì, puoi scrivermi anche nelle fasi iniziali. Possiamo valutare insieme se l'idea può trasformarsi in un progetto concreto.
